FOTOS — STARTSEITE (HOME)
=========================

Diese Fotos erscheinen auf der Startseite in 3 Gruppen.
Die Dateinamen müssen exakt so sein:

GRUPPE 1 — 3 Fotos (z.B. Innenraum / Ambiente):
  home-1.jpg
  home-2.jpg
  home-3.jpg

GRUPPE 2 — 2 Fotos (z.B. Speisen / Team / Küche):
  home-4.jpg
  home-5.jpg

GRUPPE 3 — 3 Fotos (z.B. Wein / Getränke / Abendatmosphäre):
  home-6.jpg
  home-7.jpg
  home-8.jpg

EMPFEHLUNGEN:
  - Format: JPG
  - Seitenverhältnis: Hochformat 3:4 (z.B. 600×800 Pixel)
  - Dateigröße: max. 500 KB pro Foto

HINWEIS:
  Sobald die Fotos bereit sind, müssen die Foto-Pfade im Code
  von den Platzhaltern auf /photos/home/home-1.jpg usw. umgestellt werden.
  Bitte den Entwickler (Cursor Agent) darum bitten.
  Danach: npm run build und dist/ hochladen.
