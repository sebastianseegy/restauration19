FOTOS — TEAM-SEITE
==================

3 Porträtfotos für die Team-Seite.
Die Dateinamen müssen exakt so sein:

  team-flo.jpg       → Foto von Flo
  team-krispin.jpg   → Foto von Krispin
  team-pascal.jpg    → Foto von Pascal

EMPFEHLUNGEN:
  - Format: JPG
  - Seitenverhältnis: Hochformat 3:4 (z.B. 600×800 Pixel)
  - Dateigröße: max. 500 KB pro Foto
  - Möglichst ähnliche Bildausschnitte für alle drei (gleiche Höhe, gleicher Stil)

FOTO TAUSCHEN:
  Neues Foto mit demselben Namen ablegen (altes überschreiben).
  Danach: npm run build und dist/ erneut hochladen.
