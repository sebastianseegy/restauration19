LOGOS — RESTAURATION19
======================

Das Hauptlogo liegt bereits im Ordner darüber: public/logo.svg
Dieser Ordner ist für weitere Logo-Varianten.

OPTIONALE ZUSATZ-DATEIEN:
  logo-white.svg      → Weißes Logo (für dunkle Hintergründe)
  logo-favicon.png    → Kleines Icon für den Browser-Tab (32×32 Pixel)
  logo-social.png     → Vorschaubild für Links (1200×630 Pixel, für WhatsApp / Instagram)

HAUPTLOGO TAUSCHEN:
  Das Logo das auf der Website erscheint ist: public/logo.svg
  Ersetze diese Datei durch dein echtes Logo.
  Format: SVG bevorzugt (skaliert ohne Qualitätsverlust), PNG auch möglich.
  Danach: npm run build ausführen und dist/ erneut hochladen.
